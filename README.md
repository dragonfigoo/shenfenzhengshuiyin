# shenfenzhengshuiyin
一、整体作用
给身份证照片/扫描件添加平铺式半透明水印，让图片在保持可读的同时，明确标注用途，降低被挪作他用的风险。所有处理都在浏览器本地完成，图片不会上传到服务器。

二、功能模块解析
1. 场景模板（核心亮点）
提供两套预设参数，点击即切换全套配置：

场景	基准宽度	字号	水平间距	行距	适用情况
📄 A4 纸上的身份证	2480px	40	100	200	整张 A4 扫描件
🪪 纯身份证照片	1000px	20	50	100	只拍身份证本体
关键设计是按比例自适应：参数以“图片宽度 / 基准宽度”的比值缩放。例如一张 1240px 宽的 A4 图，字号 = 40 × (1240/2480) = 20px，这样不同分辨率的图都能得到视觉一致的水印密度。

2. 自动场景识别
上传图片后根据宽高比自动判断场景：

比例 0.6~0.8 且宽度 ≥1200 → A4（A4 竖版约 0.707）
比例 1.4~1.8 → 身份证横版（约 1.58）
其他按尺寸：≥1500 判 A4，否则判身份证
识别后在页面上显示提示文字。

3. 颜色模板
预设 10 种颜色（浅蓝、浅红、浅灰、深蓝、深红、橙、绿、紫、黑、白），带名称、色值和用途说明（推荐/低调/醒目/慎用等），点击圆形色块即可切换，并同步更新颜色选择器和当前颜色显示。

4. 参数调节面板
文字大小（10~200，滑块 + 实时数值）
旋转角度（数字输入，默认 -30°）
字体（微软雅黑/宋体/黑体/楷体/Arial 等 8 种）
透明度（0~100，滑块）
水平间距、行间距（像素）
自定义颜色（color 选择器）
5. 缩放与视图
缩放滑块（10%~200%）
“适应屏幕”按钮：按容器宽高自动计算合适缩放比例
6. 实时预览与导出
多数参数（旋转、字体、透明度、间距、颜色、水印文字）修改后立即重绘
点击“添加水印”正式生成
“下载图片”按钮将 canvas 导出为 PNG
三、核心实现原理
1. Canvas 绘制流程
 复制代码 隐藏代码
redrawOriginalImage()  // 先清空并画原图
  ↓
ctx.save() + translate(中心) + rotate(角度)
  ↓
双重循环平铺文字
  ↓
ctx.restore()
2. 水印平铺算法（关键）
 复制代码 隐藏代码
const diagonal = Math.sqrt(w² + h²);          // 画布对角线
const cols = ceil(diagonal / (textWidth + hSpacing));
const rows = ceil(diagonal / vSpacing);
for (i = -rows; i < rows; i++)
  for (j = -cols; j < cols; j++)
    fillText(text, j*(textWidth+hSpacing), i*vSpacing);
以画布中心为原点旋转后，用对角线长度确保旋转后的四个角也被覆盖，-rows ~ rows 的正负范围保证左右上下都铺满。

3. 透明度实现
颜色选择器只给 RGB，透明度单独用滑块控制，通过 hexToRgba() 转成 rgba(r,g,b,alpha) 再赋给 fillStyle。

4. 状态管理
originalImage：原图对象
lastAppliedWatermark：上次水印参数快照，缩放时用它重绘
currentZoom / currentScene：当前缩放和场景
5. 实时重绘的触发链
滑块/输入框 input 事件 → 调用 applyWatermark()
applyWatermark() 内部先 redrawOriginalImage() 清除旧水印，再重新绘制
缩放时 applyZoom() 改 canvas 的 CSS 尺寸（不改内部分辨率），再重绘，保证清晰度
总体是一个纯前端、零依赖、开箱即用的实用小工具，场景模板 + 自动识别 + 实时预览的设计对普通用户很友好。
